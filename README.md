# System Health Dashboard API

## Project Objective
Build a lightweight Python Flask API and demonstrate
a Git-to-deployment workflow using Git, Docker and Jenkins.

## Project Plan
- [ ] Task 1: Plan the project
- [ ] Task 2: Build the Flask API
- [ ] Task 3: Create automated tests
- [ ] Task 4: Use Git branches and pull requests
- [ ] Task 5: Containerise using Docker
- [ ] Task 6: Automate with Jenkins

## API Endpoints
- /health - Application health status
- /version - Application version
- /environment - Current environment

## Git Branching Strategy
- main - Final reviewed application
- develop - Integration branch
- feature/* - Individual development tasks
